# 身体复位器手机版产品说明

更新日期：2026-08-01

## 1. 产品结论

可以做成手机版，而且最适合的第一版不是直接做一个重型原生 App，而是先做成可安装的移动网页 PWA。

手机版的产品形态定为：

- 专注倒计时：保留桌面版的核心入口。
- 到点复位：从“强制覆盖电脑屏幕”改成“通知 + 复位页 + 完成记录”。
- 复位库：默认提供短时动作路径，也允许导入自己的视频。
- 身体账本：记录完成过多少次复位，而不是用疼痛或体重给用户打分。
- 本地优先：原型阶段不要求账号，不上传个人视频。

产品主张：

> 每一次专注之后，都留一小段时间把身体带回来。

## 2. 目标用户

第一批用户不是专业运动人群，而是：

- 长时间使用电脑、手机的独立工作者和上班族。
- 知道应该休息，但总是等到肩颈、腰背不舒服才停下来的人。
- 已经有自己的拉伸或复位视频，希望把它们放进固定节奏的人。

核心场景：

1. 开始一轮 25–90 分钟的专注。
2. 到点后收到提醒。
3. 选择 2–8 分钟的肩颈、背部或睡前复位。
4. 完成后记入身体账本，再开始下一轮。

## 3. 手机版与桌面版的关键变化

桌面版可以控制独立窗口、托盘、全屏和本地文件夹；手机系统不允许网页稳定地长期占据前台，也不能可靠地读取电脑目录。因此手机版采用以下迁移：

| 桌面能力 | 手机版方案 |
| --- | --- |
| 全屏强制复位窗口 | 独立复位页，配合通知和全屏播放 |
| videos 文件夹 | 复位库 + 当前设备选择视频 |
| 睡眠时段循环提醒 | 先做通知开关，原生版再补系统级定时任务 |
| Windows 睡眠联动 | 原型不做；原生版接入 App 生命周期 |
| daily-stats.csv | 本地存储，后续可导出 CSV |
| 严格模式 | 以完成按钮和完成记录形成轻量承诺，不阻塞系统使用 |

## 4. MVP 功能范围

### 今日

- 显示日期和当下问候。
- 50 分钟默认专注倒计时，可在设置中改为 15–120 分钟。
- 开始、暂停专注。
- 立即复位入口。
- 今日专注时长、复位次数、复位总时长。
- 专注与复位的节奏条。

### 复位库

- 颈肩松开：6 分钟。
- 背部开窗：4 分钟。
- 睡前卸载：8 分钟。
- 导入本地视频。
- 复位进行页：动作目标、阶段进度、倒计时、暂停与完成。

### 身体账本

- 累计专注时长。
- 累计完成复位次数。
- 最近 14 天的完成记录。
- 空状态提示，不制造虚假的健康分数。

### 设置

- 专注时长。
- 通知权限。
- 对手机端能力边界的解释。

## 5. 非目标

第一版不做：

- AI 姿态诊断、医疗诊断或疼痛治疗承诺。
- 自动摄像头分析动作。
- 社区、排行榜、复杂打卡体系。
- 订阅、支付和账号体系。
- 服务端上传用户本地视频。

这些内容会显著增加隐私、合规和内容审核成本，暂时不影响“专注 → 复位 → 完成”的核心闭环。

## 6. 产品界面方向

视觉关键词：身体被叫回来、呼吸、温和的约束、少一点信息。

- 主色：深墨绿，表达安静和落地。
- 辅色：薄荷绿、暖黄、珊瑚红，分别表达恢复、节奏和动作提醒。
- 字体：标题使用有呼吸感的衬线字体，数据和按钮使用清晰的无衬线字体。
- 记忆点：呼吸灯圆环。它不是装饰，而是把“工作节奏正在进行”和“身体正在回来”放在同一个视觉中心。
- 交互原则：一个页面只突出一个下一步，不把用户带进复杂设置。

## 7. 后续版本

### V1.1：更可靠的提醒

- PWA 通知的兼容性提示。
- “稍后提醒”与“我已完成”的通知操作。
- 可设置工作时段、工作日和静默时段。
- 复位完成后自动开始下一轮专注。

### V1.5：内容与个人化

- 复位视频的标签、动作部位和强度。
- 复位播放历史。
- 自定义复位时长。
- CSV 导出。

### V2：原生 App

- 使用 Capacitor 或 React Native 封装 iOS/Android。
- 接入本地通知、后台计时和系统生命周期。
- iOS 使用 Live Activities / Focus 相关能力时，单独评估系统权限和适配范围。
- Android 使用通知渠道、前台服务或精确闹钟时，单独评估电量和系统策略。

## 8. 健康与隐私边界

产品文案只使用“帮助放松、缓解久坐紧张、建立复位习惯”等低承诺表达，不使用“矫正、治疗、治愈、修复椎间盘”等医疗化词语。

如果出现持续疼痛、麻木、无力、眩晕或运动后症状加重，产品应提示用户暂停并寻求合格医疗专业人员的判断。

原型阶段：

- 不收集账号、姓名、位置和健康档案。
- 用户导入的视频不上传。
- 统计信息只写入当前浏览器的本地存储。
