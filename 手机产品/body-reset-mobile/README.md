# 身体复位器 · 手机版原型

这是身体复位提醒器的移动 PWA 原型。它把原有桌面版的核心闭环迁移到手机：

专注倒计时 → 身体复位 → 完成记录

## 已实现

- 今日页：专注倒计时、立即复位、今日节奏。
- 复位库：颈肩、背部、睡前三条默认路径。
- 身体账本：本地统计和最近记录。
- 导入本地视频：当前设备临时播放，不上传。
- 设置：专注时长和通知权限。
- PWA manifest 与 Service Worker。

## 快速预览

直接打开 index.html 即可体验主要界面。

如果要验证安装和离线能力，请使用 HTTP 静态服务器打开该目录。

## 重要说明

当前默认动作是产品交互占位，不是医疗指导，也不代表正式内容。正式发布前需要替换为自有或已授权的动作视频，并由专业人士审阅动作说明和安全提示。

浏览器端的通知和后台计时存在平台限制。要获得更可靠的锁屏提醒，应在 PWA 验证通过后封装为 iOS/Android 原生 App。
