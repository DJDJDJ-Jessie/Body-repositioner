# Body Repositioner

身体复位提醒器是一个免安装 Windows 桌面工具，工作方式类似番茄钟：用户开始专注倒计时，到点后进入沉浸式复位窗口，播放本地身体复位视频；视频播放完成后才能回到工作。

## 功能

- 专注倒计时：开始、暂停、继续、重置、立即复位。
- 电脑解锁时可自动开始专注倒计时，手动暂停 5 分钟后可自动恢复。
- 沉浸式复位：全屏置顶播放本地视频，覆盖 Windows 任务栏。
- 没有普通复位视频时，自动显示内置的“喝口水，起来动感一下”文字休息流程，并按复位时长等待。
- 普通复位可选最短复位时长，例如 3 分钟后提前返回工作；睡眠提醒仍保持严格模式。
- 普通复位和睡眠提醒都支持 `↑` / `↓` 调节音量、音量按钮以及暂停/继续播放。
- 电脑进入睡眠时自动暂停倒计时，唤醒后会检查状态并自动继续或开启倒计时；独立的“睡眠唤醒后自动启动”功能可在程序已退出时由 Windows 事件任务重新启动程序。
- 倒计时结束时只尝试暂停当前正在播放的媒体，不会唤醒已经暂停的视频；适配支持 Windows 系统媒体会话的浏览器和常见播放器。
- 睡眠严格提醒：首次提醒间隔最多 5 分钟，电脑到点仍在使用时全屏循环播放专用提醒视频；第一次退出后，后续每 1 分钟再次提醒。
- 睡眠提醒出现时会暂停专注倒计时；睡眠提醒只能暂停/继续视频，长按 `Esc` 紧急退出后倒计时仍保持暂停。
- 视频轮播：自动选择不同视频，轮完后再进入下一轮；当天适用子文件夹的视频会和 `videos` 根目录共享视频合并播放。
- 按星期选视频：支持 `周一到周五`、`周末`、`周一` 到 `周日` 等文件夹。
- 睡眠或锁屏期间不会播放睡眠提醒视频；恢复活动或解锁后重新按间隔计时。
- 可视化设置：专注时长、视频文件夹、开机启动、解锁后自动开始、睡眠唤醒后自动启动、托盘运行、严格模式、普通复位提前返回、紧急退出。
- 设置会自动保存到 `data/settings.json`，下次打开时恢复专注/复位分钟数、睡眠提醒时段与间隔、严格模式、紧急退出时长以及两种提醒视频音量。
- 今日节奏：显示今日工作时长、运动休息次数和复位总时长。
- 身体账本：查看本周、本月数据表，并自动生成 `data/daily-stats.csv`。
- 日志分层：所有用户默认在自己的 `data` 目录保存完整日志；需要个人复盘或备份时，可以在设置中开启可选的外部日志同步。

## 技术栈

- Electron
- Vue 3
- Vite
- TypeScript
- Tailwind CSS
- lucide icons

## 开发

```bash
cd body-reset-electron
npm install
npm run dev
```

## 构建

```bash
cd body-reset-electron
npm install
npm run dist:folder
```

默认交付方式是免安装文件夹版，而不是单文件 portable exe。单文件 portable 会自解压，双击启动会更慢。

## 交付说明

最终交付时复制整个 `便携版` 文件夹：

```text
便携版/
  身体复位提醒器.exe
  videos/
  sleep-reminders/
  data/
  使用说明.md
```

`便携版/`、视频和数据不提交到代码仓库。exe 体积较大，适合通过 GitHub Releases 或其他附件方式发布。

## 日志与外部同步

程序始终把运行日志保存在当前便携版旁边的 `data/` 文件夹中：

```text
data/
  reset-log.csv
  daily-stats.csv
```

所有用户都拥有这份内部日志。设置里的“外部日志同步（可选）”只是额外复制一份到用户自己选择的文件夹，不会替代内部日志，也不会默认写入任何个人路径。

外部同步目录包含：

```text
reset-log.csv
daily-stats.csv
review-sync-manifest.json
```

外部同步失败时，内部日志仍然继续写入。发布给别人时，默认关闭外部同步，并且不要把个人 `data/` 文件夹一起打包给别人。
